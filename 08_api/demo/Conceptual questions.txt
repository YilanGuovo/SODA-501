Conceptual Question 2
The use of API key provides credentials for accessing potentially sensitive data. It help researchers retrieve and analyze data in a reproducible and secure way. If the keys are hard-coded and pushed to GitHub, especially in public repositories, others might use them. This might cause the leak of credentials and data, or even unexpected cost. An alternative approach is to store API keys as environment variables through the PowerShell on our local computers, and then introduce them in scripts. In this way, collaborators can define and use their own keys while maintaining both security and reproducibility.
